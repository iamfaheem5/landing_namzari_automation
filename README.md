# landing_namzari_automation

Astro-based landing page for **Mutation Automation** — automation for government mutation filings on `mutation.land.gov.bd` (Bangladesh land portal / নামজারি).

Built with a Linear-inspired dark design system (`#08090A` canvas, pill buttons, Inter).

See [`design.md`](./design.md) for the design contract and consistency rules.

## Dev

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
